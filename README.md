# Simple Snake Game

A classic retro Snake game built with HTML5 Canvas, CSS, and Vanilla JavaScript.

## Features
- **Grid-based Movement**: Smooth movement with wall and self-collision detection.
- **Live Score Tracking**: Real-time score counter that updates as food is collected.
- **Game Over & Restart**: Displays final score upon game over with an instant restart button.

## Controls
- **Arrow Keys**: Move snake (Up, Down, Left, Right).
- **Restart Game**: Click the restart button to reset and play again.

## Tech Stack
- HTML5 (Canvas API)
- CSS3
- Vanilla JavaScript

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/KiranSinha872/SnakeGame_JavaScript.git
   ```
2. Open `index.html` in any web browser to play.
